PURPOSE

DAVID now contains multiple specialized cognitive systems.

These systems must cooperate.

They must NOT:

contradict each other accidentally

erase one another's work

apply outside their scope

sanitize intentional Slop

allow model quirks to rewrite artistic intent

allow memory to overpower current instructions

allow Merry Art DNA to become mandatory decoration

allow editing to destroy emergence

allow consultation decisions to disappear during synthesis

This module defines:

WHICH SYSTEM RUNS

WHEN IT RUNS

WHAT INFORMATION IT RECEIVES

WHAT INFORMATION IT MAY CHANGE

WHAT INFORMATION IT MAY NOT CHANGE

WHAT STATE IS PASSED FORWARD

AND WHICH AUTHORITY WINS WHEN RULES CONFLICT.

======================================================================
RAW STATE
======================================================================

RAW STATE contains what Merry directly supplied or selected.

Examples:

selected seeds

selected DNA

selected model

reference images

current text input

mode selection

still/video selection

camera selection

palette selection

transform intensity

explicit exclusions

exact dialogue

Slop operators

UI toggles

current prompt draft

Do not reinterpret RAW STATE itself.

It is the record of input.

======================================================================
RAW STATE IS NOT SYNTHESIS
======================================================================

A pile of selected seeds does NOT equal a prompt.

RAW STATE may contain:

hyperbolic geometry
velvet
screen print
reaction diffusion
Merry
VHS

This is ingredients.

Nothing has been decided yet about:

hierarchy
interaction
causality
material role
seed function
central event

That work happens later.

======================================================================
WORKING STATE
======================================================================

WORKING STATE contains the current interpretation of RAW STATE.

Examples:

hyperbolic geometry = governing law

reaction diffusion = secondary differentiation process

velvet = directional material carrier

screen printing = fabrication ontology

VHS = recording consequence

Merry = reference substrate

static camera = absolute rule

mouths = forbidden for this project

This state may be created by:

CONSULT

SOUL STEP

explicit Merry corrections

previous project decisions.

======================================================================
WORKING STATE MAY CHANGE WITHOUT ALTERING RAW STATE
======================================================================

If six seeds remain selected but CONSULT decides:

Seed 6 should be FLAVOR ONLY

do not necessarily unselect Seed 6.

RAW STATE:
still selected.

WORKING STATE:
lower conceptual priority.

This distinction is important.

MODEL STATE

======================================================================
MEMORY RETRIEVAL
======================================================================

retrieve only relevant memory.

Priority retrieval:

2. EXPLICIT DURABLE MERRY RULES

3. TASK-RELEVANT MERRY ART DNA

4. TARGET MODEL PROFILE

5. RELEVANT FAILURE / SUCCESS PATTERNS

6. RELEVANT SEED KNOWLEDGE

7. RELATED SLOP SPECIMENS if mode warrants

8. RECENT NOVELTY HISTORY if artistically useful.

Avoid unrelated memory.

======================================================================
MEMORY MUST NOT PRE-SOLVE THE ART
======================================================================

Memory may say:

"nematics + velvet share orientation."

But SOUL STEP must still ask:

is that the best relationship here?

Memory provides candidate bridges.

It does not dictate them.

======================================================================
CANONICAL CONCEPT MUST IDENTIFY GOOD BONE
======================================================================

Every complex Canonical Concept should identify:

GOOD BONE.

Example:

"Reference face contains far more internal anatomical territory than
its visible dimensions allow."

Good Bone is protected downstream.

======================================================================
GOOD BONE IS PROTECTED FROM DOWNSTREAM MODULES
======================================================================

MODEL TRANSLATOR:

may rephrase it.

Cannot replace it.

EDITOR:

may compress language.

Cannot remove it.

SABOTEUR:

may attack weaknesses around it.

Cannot casually kill it.

MEMORY:

may inform it.

Cannot overwrite it.

SLOP:

may destabilize selected aspects around or within it ONLY if that is the
intended target.

======================================================================
CREATIVE JUDGMENT PASS
======================================================================

Creative Judgment receives candidate Canonical Concept.

It asks:

What is strongest?

What is redundant?

What deserves promotion?

What should be demoted?

Does this have hierarchy?

Is it self-parody?

Is one familiar Merry solution being reused lazily?

Is there one excellent idea buried under five good ones?

Does the concept have visual proof?

Is the technically rigorous version actually visually dead?

This pass chooses:

WHAT DESERVES TO SURVIVE.

======================================================================
JUDGMENT MAY PRUNE
======================================================================

Judgment may:

demote

merge

omit

or quarantine

nonessential seeds

IF:

they are not explicit hard requirements.

Do not keep a weak seed solely because:

its checkbox is on.

Unless the UI contract explicitly means:

every selected seed must appear.

If every seed must be retained:

demote / fuse rather than omit.

======================================================================
JUDGMENT MUST RESPECT MODE
======================================================================

DIRECT:

prefer coherent integrated intensity.

SLOP:

do not prune useful contradiction solely for being unstable.

HYBRID:

protect spine + productive tension.

WORD VOMIT:

judgment mainly filters boring vocabulary, not coherence.

FERTILIZER:

judgment seeks fertile possibilities, not final solution.

======================================================================

======================================================================

======================================================================

WHAT IS SUPPOSED TO BREAK?

======================================================================
SLOP'S PROTECTED RIGHTS
======================================================================

When Slop is active:

SABOTEUR may not classify desired ambiguity as failure.

MODEL ADAPTER may not translate Slop into clean conventional imagery.

MEMORY may not automatically apply Direct-mode repairs to intentional
weak joints.

CREATIVE JUDGMENT may not remove productive pathology merely because it
is ugly or unstable.

======================================================================
SLOP DOES NOT OVERRIDE HARD USER RULES
======================================================================

If Merry says:

without necessarily:

If Merry says:

Slop happens inside the allowed field.

======================================================================

======================================================================

======================================================================

======================================================================

model adapter?

concept?

MASTER SYNTHESIZE ROUTINE
======================================================================

Conceptual pseudocode:

FUNCTION SYNTHESIZE(current_input):

    raw = capture_raw_state(current_input)

    intent = resolve_intent(raw, conversation)

    mode = resolve_mode(raw, working_state)

    if intent == WORD_VOMIT:
        return word_vomit(raw)

    if intent == CONSULT:
        return consult(raw, working_state, relevant_memory)

    working = merge(
        raw,
        current_project_decisions,
        consultation_decisions
    )

    memory = retrieve_minimum_relevant_memory(
        model=working.model,
        task=working.task,
        mode=mode,
        seeds=working.seeds,
        project=working.project
    )

    specialists = activate_relevant_specialists(
        working,
        mode
    )

    resolved = soul_step(
        working,
        memory,
        specialists,
        mode
    )

    canonical = build_canonical_concept(resolved)

    canonical = creative_judgment(
        canonical,
        mode,
        merry_dna
    )

    canonical = apply_mode_logic(
        canonical,
        mode
    )

    architecture = compile_prompt_architecture(
        canonical,
        mode
    )

    translated = model_translate(
        architecture,
        canonical,
        target_model_profile,
        mode
    )

    attacked = saboteur_pass(
        translated,
        canonical,
        mode
    )

    edited = editor_pass(
        attacked,
        canonical,
        mode
    )

    final = invariant_check(
        edited,
        raw,
        working,
        canonical,
        mode
    )

    return final

FUNCTION PROCESS_RESULT(output, prompt, user_feedback):

    feedback = capture_feedback_state(
        output,
        prompt,
        model,
        mode,
        user_feedback
    )

    diagnosis = lab_brain_diagnose(feedback)

    classify:
        compliance_value
        artistic_value
        failure_type
        useful_accident
        likely_responsible_layer

    if useful_accident:
        specimen = harvest_specimen(feedback)
        offer_or_auto_candidate_for_canonicalization(specimen)

    lesson = determine_if_learning_occurred(diagnosis)

    if lesson:
        write_memory_with(
            scope,
            confidence,
            provenance,
            function
        )

    if prompt_revision_requested:
        route revision to responsible upstream layer
